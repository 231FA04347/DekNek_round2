🚀 DEPLOYMENT PROCESS (3 SIMPLE STEPS)
═══════════════════════════════════════════════════════════════════════

STEP 1: DEPLOY BACKEND
└─ Go to https://vercel.com
└─ Import your Backend repository
└─ Set environment variables (MONGO_URI, JWT_SECRET, NODE_ENV, PORT)
└─ Deploy
└─ Get backend URL (e.g., https://deknek-backend.vercel.app)

STEP 2: UPDATE FRONTEND
└─ Update Frontend/.env with backend URL:
   REACT_APP_API_BASE_URL=https://your-backend.vercel.app/api
└─ Commit and push changes

STEP 3: DEPLOY FRONTEND
└─ Import your Frontend repository
└─ Set REACT_APP_API_BASE_URL environment variable
└─ Deploy
└─ Get frontend URL (e.g., https://deknek-frontend.vercel.app)
